# Notex Website

Official landing page for Notex, the local-first Windows note-taking app.

## Development

Requires Node.js 20.9+.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production check

```bash
npm run build
npm run start
```

## Deployment

Import this repository into Vercel as a Next.js project. No environment variables or database are required.

## Scope

This repository contains **only** the marketing website. The desktop app lives in [shymok-nt/Notex](https://github.com/shymok-nt/Notex).

The hero product window is a **design illustration**, not an actual screenshot. The download section intentionally has no active installer link until a tested official release URL is available.
